# 07 · 桌面 · 快捷启动器

> 在桌面放双击即运行的快捷图标，免去记命令、开终端、敲命令的麻烦。
> 用 `.desktop` 文件实现（GNOME 标准快捷方式格式）。

---

## 基本原理

GNOME 桌面下，双击 `.sh` 脚本**默认用编辑器打开**（不会执行）。要实现"双击运行"，必须用 **`.desktop` 文件**——这是 Linux 桌面快捷方式的标准格式，GNOME 会把它当应用，双击直接执行。

## 目录结构

```
~/bin/shortcuts/         # 实际执行的脚本（不放桌面，保持整洁）
└── gpu-monitor.sh
~/桌面/                  # 快捷方式（.desktop 文件放这里）
└── GPU监控.desktop
```

## 示例快捷方式

| 图标 | 动作 | 创建日期 |
|------|------|---------|
| 🖥️ GPU 监控 | 在新终端打开 nvtop 实时监控 | 2026-08-07 |

## 如何使用

**双击桌面图标**即可。第一次双击 GNOME 可能弹窗问"是否信任并运行"——点"信任并启动"（已用 `gio set` 预先标记信任，正常不会问）。

退出：在 nvtop 界面按 `q`，或直接关终端窗口。

## 新增快捷方式（重要：以后照这个模板加）

### 模板：3 步加一个新图标

**第 1 步**：写实际脚本（放 `~/bin/shortcuts/`）

```bash
mkdir -p ~/bin/shortcuts
nano ~/bin/shortcuts/你的脚本名.sh
# 内容示例：
#!/bin/bash
exec 要执行的命令
```
保存后加可执行权限：
```bash
chmod +x ~/bin/shortcuts/你的脚本名.sh
```

**第 2 步**：创建桌面快捷方式（`.desktop` 文件）

```bash
nano ~/桌面/图标名.desktop
```
内容模板（**需要终端显示输出的命令**用这个）：
```ini
[Desktop Entry]
Version=1.0
Type=Application
Name=显示名
Comment=鼠标悬停时的说明
Exec=gnome-terminal --title="窗口标题" -- ~/bin/shortcuts/你的脚本名.sh
Icon=utilities-system-monitor
Terminal=false
Categories=System;
StartupNotify=true
```

**不需要终端的命令**（比如打开文件管理器、浏览器）用这个：
```ini
[Desktop Entry]
Version=1.0
Type=Application
Name=显示名
Exec=要执行的命令
Icon=图标名
Terminal=false
```

**第 3 步**：设权限 + 标记信任

```bash
chmod +x ~/桌面/图标名.desktop
gio set ~/桌面/图标名.desktop metadata::trusted true
desktop-file-validate ~/桌面/图标名.desktop   # 校验语法（无输出=正确）
```

### `.desktop` 字段说明

| 字段 | 作用 | 示例 |
|------|------|------|
| `Type` | 类型，固定 `Application` | `Application` |
| `Name` | 图标显示名（可中文）| `GPU 监控` |
| `Comment` | 鼠标悬停说明 | `打开 nvtop 监控` |
| `Exec` | **实际执行的命令** | `gnome-terminal -- nvtop` |
| `Icon` | 图标名或路径 | `utilities-system-monitor` |
| `Terminal` | 是否自带终端 | `false`（用 gnome-terminal 包了就填 false）|
| `Categories` | 分类（影响菜单归类）| `System;Monitor;` |
| `StartupWMClass` | 窗口类名（让任务栏图标正确）| `nvtop` |

### 关键坑：命令需要终端输出怎么办

`.desktop` 的 `Terminal=true` 在 GNOME 下行为不稳定。**推荐做法**：用 `gnome-terminal --` 显式包一层：

```ini
Exec=gnome-terminal --title="标题" -- 你的命令
```
然后 `Terminal=false`。这样保证命令在新终端窗口里跑，输出能看到。

### 图标怎么选

- **用系统自带图标名**（最省事）：参考 `/usr/share/icons/` 下的主题。常用：
  - `utilities-system-monitor`（系统监控）
  - `utilities-terminal`（终端）
  - `folder`（文件夹）
  - `text-editor`（编辑器）
  - `applications-internet`（网络）
- **用自定义图片**：`Icon=/绝对路径/xxx.png`（建议 256x256 PNG）

## 常见问题

### Q1：双击后用文本编辑器打开了，没运行

`.desktop` 没被标记信任。执行：
```bash
gio set ~/桌面/xxx.desktop metadata::trusted true
```
然后刷新桌面（注销重登，或 `nautilus -q` 重启文件管理器）。

### Q2：双击没反应 / 闪退

用终端调试：
```bash
# 直接运行 .desktop 看报错
gtk-launch ~/桌面/xxx.desktop
# 或验证语法
desktop-file-validate ~/桌面/xxx.desktop
```
最常见原因：`Exec` 里的命令路径写错，或脚本没加 `chmod +x`。

### Q3：图标显示成"齿轮"或空白

`Icon` 字段名写错了。用系统图标名时**不带扩展名**（写 `utilities-system-monitor`，不是 `utilities-system-monitor.png`）。

### Q4：快捷方式想放到应用菜单（不只是桌面）

把 `.desktop` 复制到 `~/.local/share/applications/`：
```bash
cp ~/桌面/xxx.desktop ~/.local/share/applications/
update-desktop-database ~/.local/share/applications/
```
之后能在应用菜单搜索到。

### Q5：想恢复"双击 .sh 直接运行"

不推荐（GNOME 44+ 默认禁用，且安全风险高）。坚持用 `.desktop` 包一层。

## 备选方案：命令行别名（alias）

如果"双击图标"还是麻烦，更多场景其实用**终端别名**更高效。在 `~/.bashrc` 加：

```bash
alias sg='rocm-smi'
alias nt='nvtop'
alias ud='sudo apt update && sudo apt upgrade -y'
```
之后终端里输 `nt` 就能跑 nvtop，比鼠标点还快。详见（如需）专门文档。
