# 27 · 工具 · 腾讯会议（Wemeet）

> 一句话：在 Ubuntu 上安装腾讯会议官方 Linux 版（deb 包），用于视频会议 / 加入他人会议 / 屏幕共享。

---

## 背景

日常办公需要加入腾讯会议（团队会议、外部客户会议多以此为标准）。腾讯官方提供 Linux 原生客户端（Qt 实现，非 Electron），Ubuntu 24.04 可直接用 `.deb` 包安装。

## 目标 / 现状

| 项目 | 内容 |
|------|------|
| 系统 | Ubuntu 24.04.4 LTS x86_64（X11 会话） |
| 安装方式 | 官方 `.deb`（x86_64） |
| 当前版本 | 3.26.10.401（2026-09-10 官网实测，Linux 版更新节奏慢于 Windows，见 Q1） |
| 包名 | `wemeet` |
| 安装路径 | `/opt/wemeet/`（约 672M，含 QtWebEngine） |
| 桌面菜单 | `/usr/share/applications/wemeetapp.desktop`（Name[zh_CN]=腾讯会议） |
| 命令行启动 | `/opt/wemeet/wemeetapp.sh`（**官方不注册 /usr/bin 命令**） |
| 用户数据 | `~/.local/share/wemeetapp` |
| 官方下载页 | https://meeting.tencent.com/download/ |

## 解决方案

### 一键执行（推荐）

```bash
# 进入仓库目录
cd <本仓库目录>

# 一键下载 + 安装 + 校验（需 sudo）
sudo bash scripts/install-tencent-meeting.sh
```

脚本会：

1. 从腾讯官方 CDN 下载 `wemeet-3.26.10.401-x86_64.deb`（约 190M）到 `~/Downloads`
2. `dpkg -i` 安装，依赖缺失时自动 `apt -f` 修复
3. 校验 `dpkg -l` / 主程序 / 桌面菜单项

### 手工步骤（理解原理用）

```bash
# 1. 下载（直链抓取方法见下方「下载 URL 拆解」）
curl -fL -o ~/Downloads/wemeet.deb \
  "https://updatecdn.meeting.qq.com/cos/72e0e0023e1d1e6d4123fba28821aea1/TencentMeeting_0300000000_3.26.10.401_x86_64_default.publish.officialwebsite.deb" \
  -A "Mozilla/5.0"

# 2. 安装
sudo dpkg -i ~/Downloads/wemeet.deb
sudo apt-get install -f -y   # 仅在报依赖错误时需要（2026-09 实测无依赖问题）

# 3. 启动：Super 键搜索 "腾讯会议"，或命令行：
/opt/wemeet/wemeetapp.sh &
```

## 参数 / 配置详解

### 下载 URL 拆解

```
https://updatecdn.meeting.qq.com/cos/<hash>/TencentMeeting_0300000000_<版本>_<架构>_default.publish.officialwebsite.deb
                                        └─与版本耦合─┘              └─x86_64 / arm64 / loongarch64─┘
```

2026-09-10 官网实测的三架构直链（升级后失效，抓法见 Q2）：

| 架构 | hash | 文件 |
|------|------|------|
| x86_64 | `72e0e0023e1d1e6d4123fba28821aea1` | TencentMeeting_0300000000_3.26.10.401_x86_64_default.publish.officialwebsite.deb |
| arm64 | `c06d6bc4a3370dbfb2f43bbc6ff8969e` | TencentMeeting_0300000000_3.26.10.401_arm64_default.publish.officialwebsite.deb |
| loongarch64 | `399aded330e344aa1327064170be86e8` | TencentMeeting_0300000000_3.26.10.401_loongarch64_default.publish.officialwebsite.deb |

**关键坑**：`/cos/<hash>/` 段与版本号一一耦合，且无法从版本号推导。升级版本时不能只改版本号，必须重新抓整条直链。

### 为什么用官方 `.deb` 而非 Flathub

| 方式 | 优点 | 缺点 |
|------|------|------|
| **官方 `.deb`（采用）** | 官方源头、版本最新、自动注册菜单项 | 直链带过期 hash，升级要重抓 |
| Flathub (`com.tencent.wemeet`) | 自动更新、沙箱 | 需先装 flatpak，版本跟进慢（社区打包） |

## 验证方法

```bash
# 1. dpkg 登记
dpkg -l wemeet
# 期望：ii  wemeet  3.26.10.401  amd64

# 2. 主程序存在
ls -la /opt/wemeet/bin/wemeetapp
# 期望：可执行文件存在

# 3. 桌面菜单项存在
grep "^Exec" /usr/share/applications/wemeetapp.desktop
# 期望：Exec=/opt/wemeet/wemeetapp.sh %u
```

GUI 冒烟测试（2026-09-10 实测通过）：

```bash
nohup /opt/wemeet/wemeetapp.sh >/tmp/wemeet-test.log 2>&1 & sleep 10
pgrep -af wemeetapp    # 主进程 + 3 个 QtWebEngineProcess 子进程存活
tail /tmp/wemeet-test.log   # 仅 libpng warning，无致命错误
pkill -f wemeetapp
```

或直接 GUI：按 Super 键，搜索 "腾讯会议"，能打开主界面即安装成功。

## 脚本用法

```bash
bash scripts/install-tencent-meeting.sh help        # 查看所有子命令

bash    scripts/install-tencent-meeting.sh download # 仅下载（不需 sudo）
sudo    scripts/install-tencent-meeting.sh install  # 仅安装
bash    scripts/install-tencent-meeting.sh verify   # 仅校验
sudo    scripts/install-tencent-meeting.sh remove   # 卸载并清理 deb 包

# 指定版本（升级时，hash 必须同时换）
sudo WEMEET_VERSION=3.xx.x.xxx WEMEET_COS_HASH=<新hash> bash scripts/install-tencent-meeting.sh all
```

## 常见问题

**Q1：Linux 版本号 3.26，Windows 都 3.45 了，是不是装错了？**

不是。腾讯会议 Linux 版官方更新节奏明显慢于 Windows/macOS（官网下载页明示各平台版本号），3.26.10.401 就是官网当前提供的 Linux 最新正式版。会议基本功能（加入/发起会议、屏幕共享、聊天）与 Windows 版互通。

**Q2：版本升级后直链失效，怎么重新抓？**

官网下载页是 Next.js 动态页面，`curl` 抓源码拿不到链接（链接由 JS 点击时才拼装）。两个实测可行的方法：

- **方法 A（浏览器控制台，推荐）**：打开 https://meeting.tencent.com/download/ ，按 F12 控制台执行：

  ```js
  // 从 React 组件 props 里抠出全部平台的下载地址
  copy($$('.mt-download-card-mini').map(e => {
    const k = Object.keys(e).find(k => k.startsWith('__reactFiber$'));
    let f = e[k]; while (f && !f.memoizedProps?.versionObj) f = f.return;
    return f?.memoizedProps?.versionObj;
  }))
  ```

  粘贴出来的 JSON 里就有 `linuxIntel.url` / `linuxArm.url` 等完整直链。

- **方法 B（F12 Network）**：打开 Network 面板 → 点页面上的「Linux · 点击下载」→ 找到返回 JSON 的 XHR 请求（含 download url 字段）。

拿到新链接后，把 URL 里的 hash 段和版本号同步更新到脚本头的 `WEMEET_COS_HASH` / `WEMEET_VERSION`。

**Q3：怎么彻底卸载？**

```bash
sudo bash scripts/install-tencent-meeting.sh remove   # 系统包 + deb 安装包
rm -rf ~/.local/share/wemeetapp                       # 用户数据（登录态/会议历史）
```

**Q4：命令行想直接敲 `wemeet` 启动？**

官方 deb 不注册 `/usr/bin` 命令。可以自建软链：

```bash
sudo ln -s /opt/wemeet/wemeetapp.sh /usr/local/bin/wemeet
wemeet &     # 之后即可这样启动
```

（注意升级重装 deb 不会破坏该软链。）

**Q5：X11 / Wayland？**

本机为 X11 会话（GNOME + AMD 双显卡），2026-09-10 实测启动正常、渲染进程无崩溃。若日后切 Wayland 会话遇到窗口/屏幕共享异常，优先怀疑 Wayland 沙箱限制，可回 X11 会话对照排查。

## 影响范围 / 安全权衡

- 安装目录 `/opt/wemeet/`（约 672M），含 Qt 运行时与 QtWebEngine
- deb 自带 `wemeetapp.desktop`，应用列表直接可见，无需手动建菜单项
- 注册 URL Scheme `%u`，浏览器内 `wemeet://` 链接可唤起客户端（用于"入会"跳转）
- 客户端会联网腾讯服务器（登录、会议、更新检查）
- 卸载不残留系统配置（用户数据在 `~/.local/share/wemeetapp`）
