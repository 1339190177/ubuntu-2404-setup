# 18 · 系统 · 默认文本编辑器（改为 VS Code）

> 把系统默认文本编辑器从 GNOME TextEditor 改为 VS Code，解决 Tabby SFTP「本地编辑」等场景下被难用编辑器打开的问题。

---

## 背景：为什么要改？

Ubuntu 24.04 默认用 **GNOME TextEditor**（`org.gnome.TextEditor.desktop`）打开文本文件。痛点场景：

- **Tabby SFTP 的「Edit locally」**：右键远程文件 → 本地编辑，Tabby 调用 `xdg-open` 打开下载到临时目录的文件，结果用 GNOME 文本编辑器打开——**没有语法高亮、没有行号、没有插件**，改代码极难用。
- **双击 .conf / .log / .yaml 文件**：同样被 GNOME 文本编辑器打开。
- **其他工具触发的「用默认编辑器打开」**：如文件管理器、IDE 的跳转等。

**根因**：`xdg-mime query default text/plain` 返回 `org.gnome.TextEditor.desktop`。`xdg-open` 根据这个 MIME 默认程序表决定打开哪个应用。

**方案**：把所有常见文本类 MIME 的默认程序改成 VS Code（`code.desktop`，已通过 Snap 安装）。

## 解决方案

### 一键修改

```bash
# 把 13 种常见文本类 MIME 的默认程序改成 VS Code
for mime in text/plain text/html application/json application/javascript application/x-yaml \
            text/x-shellscript text/x-python text/x-java text/markdown \
            application/xml text/xml text/css application/x-shellscript; do
  xdg-mime default code.desktop "$mime"
done
```

> `xdg-mime default` 写入 `~/.config/mimeapps.list`，只影响当前用户，不需要 sudo。

### 验证

```bash
xdg-mime query default text/plain          # 应输出 code.desktop
xdg-mime query default application/json    # 应输出 code.desktop
xdg-mime query default text/x-shellscript  # 应输出 code.desktop
```

## 使用场景

### 场景 1：Tabby SFTP「本地编辑」

1. 在 Tabby 的 SFTP 面板**右键**远程文件 → **Edit locally**（本地编辑）
2. Tabby 下载文件到临时目录 → **用 VS Code 打开**（之前是 GNOME 文本编辑器）
3. 在 VS Code 编辑保存
4. Tabby 监听到文件变化 → **自动上传回服务器**

> 相当于把 VS Code 当远程文件的临时编辑器，改完自动同步，很方便。

### 场景 2：文件管理器双击文本文件

Nautilus 里双击 .conf / .yaml / .json 等 → 用 VS Code 打开。

### 场景 3：命令行 `xdg-open`

```bash
xdg-open /etc/fstab          # 用 VS Code 打开
xdg-open ~/.bashrc           # 用 VS Code 打开
```

## 常见问题

### Q1：VS Code 打开很慢（首次）

Snap 应用首次启动需要几秒（挂载命名空间）。后续打开正常。如介意，可改用 deb 版 VS Code（直接 apt 安装，不走 Snap）。

### Q2：sudo 编辑系统文件（如 /etc/fstab）

`xdg-open` 和 Snap 版 VS Code 都不能直接编辑需要 sudo 的文件。用命令行：

```bash
sudo nano /etc/fstab            # 终端编辑
sudo -e /etc/fstab              # 用 $EDITOR（默认 nano）
sudo vim /etc/fstab             # vim 党
```

### Q3：想改回 GNOME 文本编辑器

```bash
xdg-mime default org.gnome.TextEditor.desktop text/plain
# 或直接删除 mimeapps.list 里 [Default Applications] 段的对应行
```

### Q4：某个特定文件类型还是用旧编辑器打开

说明那个文件的 MIME 类型不在上面 13 种里。查一下再改：

```bash
# 查文件 MIME 类型
xdg-mime query filetype /path/to/file

# 把那个 MIME 也改成 VS Code
xdg-mime default code.desktop <查到的MIME>
```

### Q5：VS Code 内想改默认终端为 Tabby

不相关——这是 VS Code 内的集成终端设置，和系统默认编辑器是两回事。VS Code 的终端在 `settings.json` 里配 `"terminal.integrated.defaultProfile.linux"`。
