# 05 · 工具 · 浏览器与默认浏览器设置

> 本机浏览器安装情况与默认浏览器配置方法。包含 Edge 从 apm 版迁移到标准 deb 版、Edge 131 崩溃修复、Chrome 安装的记录。

---

## 历史踩坑：apm 版 Edge 不能用 ⚠️

曾通过 **apm**（amber-pm，深度/星河/UOS 的包管理器）装过 Edge，但在 Ubuntu 上**启动失败**：

```
fusermount3: failed to access mountpoint: Permission denied
fuse-overlayfs: cannot mount: Operation not permitted
```

**原因**：apm 用 FUSE + overlayfs 隔离运行应用，Ubuntu 默认 FUSE 权限机制与深度系不同，普通用户无法挂载。

**教训**：apm 包装的应用是为深度/星河/UOS 设计的，**不要在 Ubuntu 上用 apm 装应用**。要用标准方式（apt/deb/snap/flatpak）。

## 历史踩坑：Edge 131 启动崩溃（trap invalid opcode）⚠️

### 现象
改装标准 deb 版 Edge 131.0.2903.86 后，**双击图标/命令行启动都秒崩**，无窗口出现。命令行报：
```
WARNING: radv is not a conformant Vulkan implementation, testing use only.
ERROR:elf_dynamic_array_reader.h(64) tag not found
追踪或断点陷阱 (核心已转储)
```
内核日志（`journalctl -k`）记录：
```
traps: msedge[xxx] trap invalid opcode ip:... error:0
```

### 排查过程（排除了多个怀疑方向）
| 怀疑 | 排查结果 | 结论 |
|------|---------|------|
| Edge 包损坏 | `dpkg -l` 正常，文件齐全 | ❌ 排除 |
| 库依赖缺失 | `ldd` 全部 resolved | ❌ 排除 |
| GPU/Vulkan 问题 | `--disable-gpu --disable-vulkan` 仍崩 | ❌ 排除 |
| AppArmor 拦截 | profile 是 `unconfined` | ❌ 排除 |
| 用户命名空间限制 | `unprivileged_userns_clone=1` 已放开 | ❌ 排除 |
| CPU 指令集不支持 | Ryzen 9700X，avx2/avx512 都有 | ❌ 排除 |
| **Edge 版本太旧** | 131 版 vs 新内核 7.0 不兼容 | ✅ **真凶** |

### 根本原因
实测环境为 **HWE 7.0 内核**（`linux-generic-hwe-24.04`），比 Ubuntu 24.04 标配的 6.8/6.11 新很多，带了新的 ELF 特性。**Edge 131（2024 年底编译）的 ELF 解析器不认识新内核带的某些库的 tag，初始化时崩溃**。

> 关键线索：`--headless=new` 能跑、有 GUI 崩溃，但根因是 ELF 加载阶段就出错，与 GUI 无关。`elf_dynamic_array_reader.h tag not found` 是 Chromium 加载带新 GNU property 的库时报的。

### 解决：升级 Edge 到最新版
```bash
# 1. 加微软官方仓库（一次性）
curl -s https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor | \
  sudo tee /usr/share/keyrings/microsoft-edge.gpg >/dev/null
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/microsoft-edge.gpg] https://packages.microsoft.com/repos/edge stable main" | \
  sudo tee /etc/apt/sources.list.d/microsoft-edge.list

# 2. 升级（131 → 151，崩溃修复）
sudo apt update
sudo apt install --only-upgrade microsoft-edge-stable

# 3. 清理旧锁文件（崩溃残留会阻止启动）
rm -f ~/.config/microsoft-edge/SingletonLock \
      ~/.config/microsoft-edge/SingletonCookie \
      ~/.config/microsoft-edge/SingletonSocket
```

升级到 **151.0.4129.72** 后正常启动。

### 教训
1. **Edge 这种闭源软件要及时升级**——微软仓库更新快，新版会修内核兼容问题。
2. **加官方仓库比手动下 deb 强**——`apt upgrade` 自动跟新，不用手动追踪版本。
3. **`elf_dynamic_array_reader.h tag not found` + `trap invalid opcode`** 这个组合，第一反应应该是**软件版本和系统库不兼容**，优先升级软件，别在 GPU/Vulkan 上浪费时间。

## 解决方案：安装标准 deb 版 Edge

### 一键安装（推荐）

```bash
# 1. 下载官方 deb（用 aria2 多线程，快）
aria2c -x16 -c -o /tmp/microsoft-edge.deb \
  "https://packages.microsoft.com/repos/edge/pool/main/m/microsoft-edge-stable/microsoft-edge-stable_131.0.2903.86-1_amd64.deb"

# 2. 安装（apt 会自动处理依赖）
sudo apt-get install -y /tmp/microsoft-edge.deb

# 3. 设为默认浏览器
xdg-settings set default-web-browser microsoft-edge.desktop
xdg-mime default microsoft-edge.desktop x-scheme-handler/http
xdg-mime default microsoft-edge.desktop x-scheme-handler/https
xdg-mime default microsoft-edge.desktop text/html

# 4. 清理安装包
rm /tmp/microsoft-edge.deb
```

> **版本更新**：上述 URL 里的版本号 `131.0.2903.86-1` 会变。最新版地址查：
> https://packages.microsoft.com/repos/edge/pool/main/m/microsoft-edge-stable/
> 或直接用微软官网下载页：https://www.microsoft.com/edge/download

### 替代方案：加微软仓库后 apt 装（自动更新）

```bash
# 加微软 GPG key 和仓库
curl https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > microsoft.gpg
sudo install -o root -g root -m 644 microsoft.gpg /etc/apt/trusted.gpg.d/
sudo sh -c 'echo "deb [arch=amd64] https://packages.microsoft.com/repos/edge stable main" > /etc/apt/sources.list.d/microsoft-edge.list'
sudo apt update
sudo apt install microsoft-edge-stable
rm microsoft.gpg
```
这种方式装的好处是 `apt upgrade` 会自动升级 Edge。

## 安装 Google Chrome

### 一键安装（推荐）

若网络可直连 `dl.google.com`（已验证）。如国内网络不通，需走代理或镜像。

```bash
# 1. 用 aria2 多线程下载官方 deb
aria2c -x16 -c -o /tmp/google-chrome.deb \
  "https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb"

# 2. 安装（会自动加 Google apt 仓库，以后 apt upgrade 自动更新）
sudo apt-get install -y /tmp/google-chrome.deb

# 3. 清理
rm /tmp/google-chrome.deb
```

### 验证

```bash
google-chrome --version           # 应输出版本号
google-chrome about:blank         # 应弹出窗口
```

### 网络问题（国内访问 Google）

`dl.google.com` 在国内**有时连不上**。处理方式：
1. **走代理**：`https_proxy=http://代理:端口 aria2c ...`
2. **国内镜像**：Chrome 国内分发较严，无稳定官方镜像。可考虑：
   - 用 Edge 代替（微软仓库国内可访问）
   - 用 Chromium（`sudo apt install chromium`，但 snap 版有沙箱限制）
   - 用淘宝/华为镜像搜 `google-chrome` deb（非官方，谨慎）

> 可直连时无需上述处理。

### Chrome 与 Edge 共存

两个浏览器可同时安装，互不冲突。默认浏览器设置见下方「默认浏览器设置方法」。

**切换默认到 Chrome**：
```bash
xdg-settings set default-web-browser google-chrome.desktop
xdg-mime default google-chrome.desktop x-scheme-handler/https
xdg-mime default google-chrome.desktop x-scheme-handler/http
```

**切回 Edge**：
```bash
xdg-settings set default-web-browser microsoft-edge.desktop
xdg-mime default microsoft-edge.desktop x-scheme-handler/https
xdg-mime default microsoft-edge.desktop x-scheme-handler/http
```

### Chrome 不崩溃的关键（关联 Edge 131 教训）

HWE 7.0 内核下，旧版 Chromium 系（如 Edge 131）会因 ELF 解析不兼容崩溃。Chrome 151 版正常，但**切记不要禁用 Chrome 自动更新**——旧版会重蹈 Edge 131 崩溃覆辙。

## 卸载 apm 版 Edge（如果还在）

```bash
# 1. 用 apm 卸载（非交互）
sudo DEBIAN_FRONTEND=noninteractive apm remove -y microsoft-edge-stable

# 2. 清理残留
rm -rf ~/.apm/microsoft-edge-stable
sudo rm -f /usr/local/share/applications/microsoft-edge.desktop
sudo rm -f /usr/local/share/applications/com.microsoft.Edge.desktop

# 3. 验证
dpkg -l | grep microsoft-edge   # 应无输出
```

## 默认浏览器设置方法（通用）

Ubuntu 的"默认浏览器"分**三层**，建议都设置一致：

### 第 1 层：xdg-settings（管终端、xdg-open）

```bash
# 查看
xdg-settings get default-web-browser

# 设置（值是 .desktop 文件名，不带路径）
xdg-settings set default-web-browser microsoft-edge.desktop
xdg-settings set default-web-browser firefox_firefox.desktop
```

### 第 2 层：xdg-mime（管点链接、打开 html）

```bash
# 关联 http/https/html 到某浏览器
xdg-mime default microsoft-edge.desktop x-scheme-handler/http
xdg-mime default microsoft-edge.desktop x-scheme-handler/https
xdg-mime default microsoft-edge.desktop text/html

# 查询当前关联
xdg-mime query default x-scheme-handler/https
```

### 第 3 层：GNOME 设置（管图形应用，如聊天软件点链接）

```
设置 → 应用 → 默认应用 → 网络 → 网页
```
或命令打开：
```bash
gnome-control-center default-apps
```

### 第 4 层：update-alternatives（系统命令链）

```bash
# 查看可选浏览器
update-alternatives --list gnome-www-browser

# 交互式选择
sudo update-alternatives --config gnome-www-browser
```

> **日常使用**：改第 1、2 层（xdg-*）就够覆盖 99% 场景。第 3 层在 GNOME 设置里点一下。第 4 层一般装 deb 时自动配好，不用手动动。

## 验证默认浏览器

```bash
# 1. 看设置值
xdg-settings get default-web-browser
xdg-mime query default x-scheme-handler/https

# 2. 实测（会打开默认浏览器访问该网址）
xdg-open https://www.microsoft.com
```

## 常见问题

### Q1：图形应用点链接还是用 Firefox

GNOME 缓存了默认应用。两步解决：
1. 进「设置 → 应用 → 默认应用」手动选 Edge
2. 注销重登一次（或重启 gnome-shell：`Alt+F2` 输入 `r`）

### Q2：snap 版 Firefox 的 .desktop 名字很怪

snap 应用的 desktop 文件名带 `_` 前缀和后缀，比如 `firefox_firefox.desktop`。用这个命令查准确名字：
```bash
ls /var/lib/snapd/desktop/applications/ | grep -i firefox
```

### Q3：Edge 启动慢/卡

Edge 首次启动会初始化配置，属正常。后续启动慢的话关掉启动时的"睡眠"功能：
Edge 设置 → 系统和性能 → 关闭"启动增强"和"睡眠标签页"。

### Q4：apm 还留着，要不要卸载

apm 是深度系包管理器，如果你不用深度/UOS 系应用（如微信 apm 版、7-Zip apm 版），可以一并卸载：
```bash
sudo apt-get purge -y apm amber-pm-deepin20
```
但如果你在用 `~/.apm/` 下的 wechat 等，就先别卸。

### Q5：桌面重装/依赖级联把浏览器卸没了（2026-09-15 实例）⚠️

修显示问题重装 xserver/gdm3 时，依赖级联把 `google-chrome-stable`、`microsoft-edge-stable`
一并卸走（手工加的外部仓库包，不在 ubuntu-desktop 依赖保护圈内）。特征：`dpkg -s` 显示
`deinstall ok config-files`。

恢复要点：**apt 仓库配置（`/etc/apt/sources.list.d/`）和 `~/.config` 下的用户数据
（书签/登录/扩展）都幸存**，直接装回即可，无需迁移数据：

```bash
sudo apt-get update
sudo apt-get install -y google-chrome-stable microsoft-edge-stable
```

若 Edge 仓库报 `NO_PUBKEY EB3E94ADBE1229CF`：钥匙文件 `/usr/share/keyrings/microsoft-edge.gpg`
还在，但 `microsoft-edge.list` 里缺 `signed-by=` 指向它（`/usr/share/keyrings/` 下的钥匙
apt 不会自动加载，必须显式指定）。按本文「升级 Edge 到最新版」一节的写法重写 list 即可。
