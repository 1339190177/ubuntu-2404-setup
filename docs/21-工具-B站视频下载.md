# 21 · 工具 · B站视频下载（BBDown）

> 在 Ubuntu 上替代 Windows 时代的唧唧/Downkyi 等 B 站下载 GUI：装 BBDown 命令行工具，扫码登录后可下 1080P/4K，支持收藏夹、UP 主批量、番剧课程。

---

## 背景

Windows 上下载 B 站视频用惯了 GUI 软件（唧唧、Downkyi 等），换到 Ubuntu 后没有现成对应物。
B 站网页端不提供下载，手机端缓存又拿不到原片文件，需要一个 Linux 下可用的下载方案。

## 目标 / 现状

| 项目 | 内容 |
|------|------|
| 系统 | Ubuntu 24.04 x86_64 |
| 选定工具 | BBDown v1.6.3（B 站专用，nilaoda/BBDown） |
| 安装位置 | `~/bin/BBDown`（单文件自包含，内带 .NET runtime，零外部依赖） |
| 已有依赖 | ffmpeg `/usr/bin/ffmpeg`（混流）、aria2c `/usr/bin/aria2c`（可选多线程下载） |
| 实测日期 | 2026-08-16 |

### 选型对比（为什么是 BBDown）

| 方案 | B 站支持 | 登录方式 | 结论 |
|------|---------|---------|------|
| **BBDown** | 专用：分P/番剧/课程/收藏夹/UP主批量 | `BBDown login` 终端扫码 | ✅ 首选，B 站体验最全 |
| yt-dlp（若已有，`~/.local/bin/yt-dlp`） | 通用支持，需手动导 cookies | `--cookies-from-browser` 等 | 备用：下其他网站时用它 |
| lux（原 annie） | 支持但更新一般 | 手动 cookies | 不选 |

> 分工约定：**B 站 → BBDown，其他网站 → yt-dlp**。yt-dlp 也能下 B 站，但登录要导 cookies、批量功能弱，只做兜底。

### 分发方式判断（对照 docs/20 的两种模式）

BBDown 官方 GitHub releases 提供 **linux-x64 自包含 zip 稳定直链**（单可执行文件，
内含 .NET runtime），属于"官方有稳定直链"类型 → **宿主机直装 `~/bin`**，不走 Docker。

## 解决方案

### 一键执行（推荐）

```bash
cd <本仓库目录>
bash scripts/install-bbdown.sh            # 安装 + 校验（无需 sudo）
bash scripts/install-bbdown.sh login      # 扫码登录，解锁 1080P+ 画质
                                         # （官方 API 直连，BBDown 1.6.3 自带 login 已失效，见 Q1）
```

脚本内部逻辑：GitHub API 查最新版 → 依次尝试「直连 → ghfast.top → ghproxy.net」下载 →
解压安装到 `~/bin/BBDown` → 校验版本/PATH/ffmpeg。

### 手工步骤（理解原理用）

```bash
# 1) 下载（本机直连 release-assets 资产域名超时，直接走镜像）
curl -L -o /tmp/bbdown.zip \
  "https://ghfast.top/https://github.com/nilaoda/BBDown/releases/download/1.6.3/BBDown_1.6.3_20240814_linux-x64.zip"

# 2) 解压（zip 里就一个自包含可执行文件，无依赖）
unzip -o /tmp/bbdown.zip -d /tmp/bbdown

# 3) 装进 ~/bin（已在 PATH，docs/20 的 TDengine wrapper 也在这里）
install -m 755 /tmp/bbdown/BBDown ~/bin/BBDown

# 4) 确认
BBDown --help | head -1
# → BBDown version 1.6.3, Bilibili Downloader.

# 5) 扫码登录（可选但强烈建议，见下文"未登录 480P 限制"）
BBDown login
```

## 常用命令速查

```bash
# 单个视频（av 号 / BV 号 / 完整链接都认）
BBDown "https://www.bilibili.com/video/BV1GJ411x7h7"
BBDown BV1GJ411x7h7

# 只解析不下载，看标题/时长/可用画质
BBDown -info BV1GJ411x7h7

# 指定画质优先级（默认从高到低自动选）
BBDown -q "1080P 高码率, 1080P 清晰, 720P" BV1GJ411x7h7

# 交互式选清晰度（列出所有流让你挑）
BBDown -ia BV1GJ411x7h7

# 批量：UP 主全部投稿 / 收藏夹 / 番剧(ss) / 课程
BBDown "https://space.bilibili.com/486906719"
BBDown "https://www.bilibili.com/medialist/detail/ml123456"
BBDown "https://www.bilibili.com/bangumi/play/ss12345"

# 只下音频（当歌曲下）/ 只下弹幕 / 只下字幕
BBDown --audio-only BV1GJ411x7h7
BBDown --danmaku-only BV1GJ411x7h7

# 指定下载目录（默认当前目录）
BBDown --work-dir ~/Videos/B站 "https://www.bilibili.com/video/BV1GJ411x7h7"

# 用 aria2c 多线程下载（大文件更快，本机已装 aria2c）
BBDown -aria2 "https://www.bilibili.com/video/BV1GJ411x7h7"

# 登录相关（注意：BBDown 1.6.3 自带的 login 已失效，用仓库脚本登录，见 Q1）
bash <本仓库目录>/scripts/install-bbdown.sh login   # 扫码登录（官方 API 直连）
rm ~/bin/BBDown.data                                       # 登出 = 删除凭据文件
```

## 脚本用法

```bash
bash scripts/install-bbdown.sh install   # 仅安装
bash scripts/install-bbdown.sh verify    # 仅校验（命令/版本/PATH/ffmpeg）
bash scripts/install-bbdown.sh login     # 扫码登录
bash scripts/install-bbdown.sh update    # 升级到 GitHub 最新版
bash scripts/install-bbdown.sh remove    # 卸载（可选删 ~/.BBDown 凭据）
bash scripts/install-bbdown.sh help      # 帮助
```

> 版本策略：脚本优先用 GitHub API 自动取最新 release 的 linux-x64 资产；API 不通时
> 回退脚本内置的 `FALLBACK_VERSION`（手动升级时改脚本头部变量即可）。

## 常见问题

**Q1：`BBDown login` 明明扫码成功了，为什么还是提示未登录、只有 480P？**
两层原因：
- 未登录只能拿 480P 及以下；登录后可下账号权限内的最高画质（普通号 1080P，大会员
  1080P高码率/4K/杜比）。
- BBDown 1.6.3 自带 `BBDown login` 对 B 站改版后的登录接口失效：B 站现在把 cookie 放在
  poll 响应的 **Set-Cookie 响应头**里，响应体 `cookie_info.cookies` 已为空，BBDown 只解析
  响应体 → 扫码确认显示"登录成功"但 `SESSDATA=` 为空，之后永远未登录。
  **解决**：`bash scripts/install-bbdown.sh login`——直接调官方 qrcode generate/poll 接口，
  从响应头提取 cookie 写入凭据文件 `~/bin/BBDown.data`（与二进制同目录，cookie 字符串
  格式 `SESSDATA=...; bili_jct=...; DedeUserID=...`）。实测 2026-08-16：登录后同一视频
  可用画质从 480P 变为 1080P 高码率。
- 手工修凭据：任何途径拿到合法 cookie 后，往 `~/bin/BBDown.data` 写一行
  `SESSDATA=xxx; bili_jct=yyy` 即可被 BBDown 识别。

**Q2：下载时刷屏 `Multiple -c, -codec ... options specified` 警告？**
无害。这是 BBDown 调 ffmpeg 合并字幕流时的参数写法触发的提示，产物正常，忽略即可
（本机实测该警告下合并结果时长/体积均正确）。

**Q3：GitHub 下载失败？**
本机网络实测：`github.com` 主站可达，但 `release-assets.githubusercontent.com`（资产实际
域名）超时。脚本已内置三个下载源依次尝试；若镜像站也失效（这类服务不稳定），手动换一个
GitHub 加速前缀拼在完整 URL 前面即可。

**Q4：下载的文件在哪？**
默认当前工作目录，文件名形如 `【标题】.mp4`。用 `--work-dir` 指定目录，用 `--file-pattern`
自定义命名模板（如 `--file-pattern "{{title}}-P{{page}}"`）。

**Q5：和已有的 yt-dlp 什么关系？**
不冲突。B 站用 BBDown（登录/批量/番剧体验好）；YouTube 等其他网站继续用 yt-dlp。

**Q6：番剧/课程下不动？**
部分内容需要 TV 端解析或登录态：试 `BBDown logintv` 后加 `-tv` 参数；大会员内容需要
账号本身有大会员。

## 影响范围 / 安全权衡

- 纯用户态安装：只新增 `~/bin/BBDown` 一个文件 + `~/.BBDown/` 凭据目录，不碰系统目录，卸载即净。
- 登录凭据 `~/bin/BBDown.data` 含 B 站登录态，等同于账号密码，不要拷贝给别人。
- 下载内容仅限个人学习/存档，遵守 B 站用户协议与版权法律，勿传播再上传。
