# 23 · 工具 · 网文阅读器（阅读3服务器版）

> 用 Docker 自托管「阅读3服务器版」，浏览器免费、无广告追网文：书架/换源/听书/多端进度同步，手机同网段可直接访问。

---

## 背景

追网文的痛点：主流"免费小说 App"（七猫/番茄类）靠广告盈利，开屏、插页、悬浮窗不断。真正免费无广告的路只有一条——**开源自托管 + 社区书源**。

选型结论（2026-08-22 调研）：

| 方案 | 结论 |
|------|------|
| **阅读3服务器版**（hectorqin/reader） | ✅ 选它。Legado 书源生态（海量社区书源），浏览器即用，Docker 部署 |
| ReadCat | ❌ 理念对口（跨平台+书源+无广告）但内测期无正式 Release，下载渠道不稳 |
| Koodo Reader / Readest / Foliate | 本地电子书阅读器（EPUB/TXT 文件），无书源概念，不解决"追网文" |
| Legado 原版 + 安卓模拟器 | ❌ 太重 |

## 现状

- 镜像：`ddsderek/reader:latest`（v3.2.14，184MB）
- 数据：`~/docker/reader/`（storage 存书源/书架/进度，是唯一要备份的目录）
- 端口：`127.0.0.1:4395 → 8080`（**仅本机可访问**），资源限额 CPU≤1 核、内存≤1G
- 书源：XIU2 精品书源 22 条（脚本 `sources` 子命令自动导入）
- 桌面入口「阅读」已生成

## 解决方案

### 一键执行（推荐）

```bash
cd <本仓库目录>
sudo bash scripts/install-reader-docker.sh          # pull → compose → 桌面入口 → 校验
```

### 手工步骤（理解原理用）

```bash
# 数据目录（~/docker 属主是 root，需要 sudo）
sudo mkdir -p ~/docker/reader/{storage,log,file-uploads}

# compose 内容见脚本 write_compose()，三个卷的含义：
#   ./storage       书源/书架/阅读进度（核心数据）
#   ./log           应用日志
#   ./file-uploads  书源"文件导入"的临时目录（见下方坑 3）

cd ~/docker/reader && sudo docker compose up -d
curl http://localhost:4395/      # 标题「阅读」即成功
```

### 首次使用：书源已自动导入

单用户模式（`SPRING_PROFILES_ACTIVE=prod`）**免登录**，浏览器打开直接用。
书源由脚本 `sources` 子命令经 REST API 自动导入（XIU2 精品书源 22 条），装完即搜即读：

```text
1. 打开 http://localhost:4395
2. 左侧搜索框输入书名 → 多源搜索 → 加入书架 → 开读
```

**书源维护**（换书源包 / 某源失效时）：

```bash
# 重新导入/更新（同链接重复导入会做更新而非重复）
sudo bash scripts/install-reader-docker.sh sources
```

或网页「导入书源 → 网络导入」手动粘贴链接：

| 链接 | 说明 |
|------|------|
| `https://ghfast.top/https://raw.githubusercontent.com/XIU2/Yuedu/master/shuyuan` | GitHub 镜像分流 |
| `https://bitbucket.org/xiu2/yuedu/raw/master/shuyuan` | Bitbucket 直链 |

> 书源是易耗品：某本书打不开/搜不到，先换源（阅读页菜单里有"换源"），再考虑换书源包。
> 更多书源可在书源社区（如 legado.aoaostar.com）自行挑选。

### 手机/平板追更

默认绑定 `127.0.0.1`，手机不能直连。两个选择：

```text
方案 A（临时，安全）：手机装 SSH 客户端（如 Termius）建隧道
  ssh -L 4395:127.0.0.1:4395 $USER@192.168.1.13
  手机浏览器开 http://localhost:4395

方案 B（长期）：放开为局域网可访问
  sudo READ_BIND=0.0.0.0 bash scripts/install-reader-docker.sh install
  手机访问 http://192.168.1.13:4395（代价见下方安全权衡）
```

## 关键坑（全部本机实测，2026-08-22）

1. **上游已"跑路"，官方镜像拉不到**
   `hectorqin/reader` 仓库 2026-06 归档且 README 被清空，Docker Hub 官方镜像同步删除：
   ```
   Error: manifest unknown: 官方仓库可能已删除该镜像
   ```
   → 改用社区转存镜像 **`ddsderek/reader`**（同源码构建，附加 PUID/PGID/Umask 支持）。
   后续它若也消失，去 Docker Hub 搜 `reader` 找新转存，或从 fork 源码自行构建。

2. **daemon.json 里的加速站半死不活**
   4 个配置的加速站实测只剩 `docker.1ms.run` 和 `docker.m.daocloud.io` 能用；
   `docker.xuanyuan.me`、`dockerproxy.com` 已失效（且 daemon 配置了加速站时直连错误仍会裸露）。
   → 脚本内置 fallback 链：直连 → 1ms.run → daocloud，拉到后统一 retag 成 `ddsderek/reader:latest`。

3. **书源"文件导入"报 500 AccessDenied**
   Vert.x 上传临时目录写死在容器根 `/file-uploads`，容器用户 uid 1000 无权在 `/` 建目录：
   ```
   AccessDeniedException: /file-uploads
   ```
   → compose 里显式挂载 `./file-uploads:/file-uploads`（脚本已内置）。网络导入不受影响。

4. **`~/docker` 属主是 root**
   Docker data-root 建的目录，普通用户 mkdir 报"权限不够"。
   → 脚本必须 `sudo` 运行（脚本内有检查并提示）。

5. **XIU2 书源老链接已失效**
   网上教程普遍写的 `xiu2.github.io/yuedu/shuyuan.json` 已 404，且新链接**不带 `.json` 后缀**。
   → 用上表验证过的链接；README 里的其它分流（jsdmirror/wget.la 等）任选能用的。

6. **REST API 前缀是 `/reader3/`，不带前缀一律 404**
   前端 axios 的 baseURL 拼接让浏览器请求看起来和裸路径一样，curl 裸打 `/getBookSources`
   会得到 HTML 404，极易误判"服务坏了"。可用的接口（单用户模式免鉴权）：
   ```
   GET  /reader3/getSystemInfo                 # 系统信息
   POST /reader3/getBookSources   -d '{}'      # 列书源
   POST /reader3/saveBookSources  --data-binary @书源.json   # 导入/更新书源
   ```

7. **页面弹「没有备份文件,请修复」**
   脚本走 API 导书源绕过了"登录初始化"，用户配置文件（userConfig）不存在，
   前端启动调 `getUserConfig` 拿到 `errorMsg:"没有备份文件"` 就弹窗。
   → 修复：`POST /reader3/saveUserConfig -d '{}'` 补一份空配置；
   脚本 `init_user_config` 已内置（只在缺失时补，不覆盖用户已保存的配置）。

## 常见问题

**Q1：某本书某一章加载失败？**
阅读页菜单「换源」切到其它书源，进度不丢。书源整体失效就重新导入书源包。

**Q2：想听书？**
阅读界面有朗读按钮（TTS）；中文效果一般，重度听书需求建议配合系统 TTS 或另配 httpTTS 引擎（「替换规则」旁的 TTS 设置）。

**Q3：数据在哪？怎么备份？**
全部在 `~/docker/reader/storage/`。备份即拷目录；网页端「用户空间 → 下载数据备份」可导出 JSON。

**Q4：升级怎么做？**
上游已停更，镜像基本冻结。若 ddsderek 有更新：`docker rmi ddsderek/reader:latest && sudo bash scripts/install-reader-docker.sh pull` 再 `up -d`（数据不丢）。

## 影响范围 / 安全权衡

- **监听 `127.0.0.1:4395`（默认，仅本机）**：局域网/手机均不可直连，最安全。
  要手机访问：SSH 隧道（见上文），或 `READ_BIND=0.0.0.0` 重跑 install——代价是同网段
  任何人都能打开并看到书架（单用户免登录）；介意再加多用户模式
  `SPRING_PROFILES_ACTIVE=prod_multuser` + `READER_APP_SECUREKEY=密码`。
- **资源限额 CPU≤1 核 / 内存≤1G**：JVM(openjdk-8u191+) 按 1G 容器限额自适应堆（约 256M），
  实测空闲占用 ~445MiB，余量充足。要调：`CPU_LIMIT=2.0 MEM_LIMIT=2g` 重跑 install。
- 容器以 uid 1000 运行（PUID/PGID），无特权，restart=unless-stopped 开机自启。
- 书源来自第三方网站，内容可用性随源站波动，与本项目无关。
