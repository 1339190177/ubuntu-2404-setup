# 29 · 工具 · 一键水印（右键加水印）

> 一句话：文件管理器里选中图片 → 右键 → 脚本 → 添加文字水印 → 同目录生成带水印新图。不打开任何软件，不学任何概念。底层 ImageMagick，单张 30 毫秒。

---

## 背景

docs/28 装了 GIMP 后实际用起来发现：加个水印要"打开软件 → 文字工具 → 图层 → 不透明度 → 导出"五步，工具专业但**日常场景太重**。需求本质是"这几张图发出去之前盖上自己的署名"，正确形态应该是**右键一下就完事**。

| 场景 | 用什么 |
|------|--------|
| 日常给图片加水印（99% 的情况） | **本篇：右键 / `watermark` 命令** |
| 精修、抠图、复杂排版、去水印 | GIMP（docs/28） |

选型：底层用 ImageMagick 而非 GIMP 无头，因为实测 GIMP 无头单张要 10 秒+（还踩了 docs/28 记录的三坑），convert 只要 **0.03 秒**，且毫秒级才配得上"右键即得"的体验。

## 目标 / 现状

| 项目 | 内容 |
|------|------|
| 底层 | ImageMagick 6.9.12（apt，`convert`/`identify`） |
| 字体 | Noto Sans CJK SC（系统已有，中文渲染实测正常） |
| CLI | `~/bin/watermark`（`~/.profile` 默认含 `~/bin`，新终端直接可用） |
| 右键入口 | `~/.local/share/nautilus/scripts/添加文字水印` |
| 默认水印 | `$USER · 版权所有`，右下角，半透明白（0.65），字号自适应 |
| 输出规则 | `原名_wm.扩展名`，**绝不覆盖原图** |
| 速度 | 单张 ≈ 30ms（2026-09-14 实测） |

## 解决方案

### 一键执行（推荐）

```bash
cd <本仓库目录>
sudo bash scripts/install-watermark.sh      # 装 imagemagick + 部署 CLI + 右键脚本
```

### 日常用法（装完后）

**傻瓜式（推荐）**：

```text
文件管理器(Nautilus)里选中 1 张或多张图片 → 右键 → 脚本 → 添加文字水印
→ 桌面右上角弹"水印完成"通知 → 同目录出现 原名_wm.jpg
```

**命令行（想自定义时）**：

```bash
watermark 图片.png                          # 默认文字，右下角
watermark -t "内部资料 禁止外传" a.jpg       # 自定义文字
watermark -o northwest -a 0.8 a.jpg         # 左上角，更不透明
watermark -p 28 a.jpg                       # 字更小（字号=图宽/28，默认 18）
watermark a.jpg b.png c.webp                # 多文件
for f in *.jpg; do watermark "$f"; done     # 整个目录
```

| 参数 | 含义 | 默认 |
|------|------|------|
| `-t "文字"` | 水印文字 | `$USER · 版权所有` |
| `-o 位置` | `southeast`/`southwest`/`northeast`/`northwest`/`center` | `southeast`（右下） |
| `-p 分母` | 字号 = 图片宽 ÷ 分母 | `18` |
| `-a 透明度` | 0~1，1 为不透明 | `0.65` |

## 常见问题

**Q1：右键菜单里看不到「脚本」菜单项？**

Nautilus 右键菜单的「脚本」子菜单只有当 `~/.local/share/nautilus/scripts/` 里有可执行文件时才出现。装完本工具就有了；若 Nautilus 一直开着老进程，关掉所有文件管理器窗口重开（或 `nautilus -q` 再打开）。

**Q2：右键处理后没反应/没弹通知？**

看日志 `/tmp/nautilus-watermark.log`。常见原因：选中的不是受支持格式（支持 jpg/jpeg/png/webp/bmp/gif/tiff）；或 `~/bin/watermark` 被删（重跑 `sudo bash scripts/install-watermark.sh install`）。

**Q3：新终端里 `watermark` 提示 command not found？**

`~/.profile` 默认把 `~/bin` 加进 PATH（2026-09-14 实测 zsh 交互环境也继承，`command -v watermark` 直接命中）。若遇到找不到：当前终端 `source ~/.profile` 或重开终端。

**Q4：想改默认水印文字（不想每次 -t）？**

编辑 `~/bin/watermark`，把 `TEXT="$USER · 版权所有"` 改成想要的文字。注意脚本由 `install-watermark.sh` 部署，**重跑 install 会覆盖回去**，改动要重新做。

**Q5：想要满图平铺水印（防盗用那种铺满全图的）？**

平铺需要多行重复绘制，一行 convert 命令做不好看。建议：GIMP 里做好一个平铺水印模板图（透明 .png），之后批量合成：

```bash
convert 原图.jpg 水印模板.png -gravity center -composite out.jpg
```

**Q6：GIMP（docs/28）还需要吗？**

按需保留：一键水印覆盖"加水印"；GIMP 用于抠图/精修/去水印/复杂文字排版。只用一键水印的话，`sudo bash scripts/install-gimp.sh remove` 可卸载 GIMP（约省 108MB+）。

**Q7：`convert` 报 `attempt to perform an operation not allowed by the security policy`？**

IM6 的 policy.xml 限制了某些操作（如读 PDF/特大图）。加水印用的 annotate 不受限；若遇到，检查 `/etc/ImageMagick-6/policy.xml` 是否被改过。

## 影响范围 / 安全权衡

- 系统：仅新增 apt 包 `imagemagick`（无后台服务、无自启）
- 用户目录：`~/bin/watermark`、`~/.local/share/nautilus/scripts/添加文字水印` 两个文件
- 不覆盖任何原图（固定 `_wm` 后缀输出），处理 JPEG 固定 quality 92
- 纯本地处理，图片不出机器
- 日志 `/tmp/nautilus-watermark.log` 只记录时间与错误，不含图片内容，重启自动清
